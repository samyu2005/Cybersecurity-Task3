# Task 3: Perform a Basic Vulnerability Scan on Your PC

## Objective

To identify common vulnerabilities on a computer using a free vulnerability scanning tool.

## Tool Used

* Nessus Essentials

## Scan Target

* 127.0.0.1 (Local Host)

## Procedure

1. Installed Nessus Essentials.
2. Activated the product using the free Essentials license.
3. Configured a Basic Network Scan.
4. Set the target as 127.0.0.1.
5. Started the vulnerability scan.
6. Reviewed the scan results and findings.

## Scan Results

* Scan Status: Completed
* Scan Duration: 15 Minutes
* Total Findings: 96

## Critical Vulnerabilities and Mitigations

### Open Network Services

**Risk:** Unnecessary services may expose the system to attacks.

**Mitigation:** Disable unused services and close unnecessary ports.

### Outdated Software Components

**Risk:** Old software versions may contain known vulnerabilities.

**Mitigation:** Update the operating system and applications regularly.

### Security Configuration Issues

**Risk:** Weak security settings can increase system exposure.

**Mitigation:** Apply recommended security configurations and security patches.

### Authentication Failure

**Risk:** Some vulnerabilities may not be fully detected.

**Mitigation:** Use authenticated scans with proper credentials.

## Conclusion

The vulnerability assessment was successfully completed using Nessus Essentials. The scan identified several findings and provided useful insights into system security. Appropriate mitigation steps were documented to improve the security posture of the system.
